**#Customer Sales Data Cleaning and Analysis Using Microsoft Excel**

**Objective**

The objective of this project is to clean and transform raw customer sales data into a structured and reliable dataset. The project demonstrates how Microsoft Excel can be used to improve data quality. It also shows how to analyze sales performance and build an interactive dashboard that supports business decision making.

**Project Overview**

This project starts with a raw customer sales dataset containing missing values. Duplicate records. Inconsistent text. Invalid entries. Different date formats. The data is cleaned and validated using Microsoft Excel functions and tools. Pivot Tables and Pivot Charts are then created to generate meaningful business insights. Finally an interactive dashboard is designed to present the results in a clear and professional format.
